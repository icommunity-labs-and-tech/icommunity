# CONTEXT.md — iCommunity

## About this project

This is the main website and product platform for **iCommunity Labs & Tech S.L.** (iCommunity.io).

iCommunity is the core infrastructure company behind all of Miguel Angel Pérez's ventures.

---

## What iCommunity does

**Tagline:** "Turn digital processes into auditable evidence."

iCommunity is a **Trust Infrastructure platform** for regulated environments. It converts digital operations into verifiable, tamper-proof evidence ready for audit and regulatory oversight — from the moment they are created.

Core positioning: **Independent Regulatory Trust Infrastructure.**

The key insight: in traditional systems, the entity that executes a process also generates the evidence. iCommunity separates execution from certification, creating an independent auditable record.

---

## Core capabilities

- **KYC event evidence** — cryptographic receipt for each identity verification (onboarding, document validation, liveness check)
- **Age verification evidence** — certifies that age checks were performed correctly
- **Human interaction evidence (anti-fraud)** — immutable proof that an action was performed by a real person (CAPTCHA, biometrics, bot detection)
- **Supply chain event certification** — traceability of origin and transport
- **AI decision auditing** — algorithmic decision records

---

## How it works (3 steps)

1. **Capture** — receives verification event from the source system (KYC provider, fintech, etc.) and normalizes it
2. **Certify** — automatically generates cryptographic proof with timestamp and immutable record (hash + timestamp + blockchain anchor)
3. **Verify / Audit** — query public verifier or export complete evidence for any audit

Integration via: SDK · API · Webhook. No friction with existing systems.
